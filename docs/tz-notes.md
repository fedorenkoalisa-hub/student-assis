## Функціональні вимоги

- Перегляд списку: відображення всіх поточних завдань
- Створення завдання: додавання нового запису (назва, дедлайн, пріоритет)
- Зміна статусу: відмітка завдання як виконаного або активного
- Редагування: оновлення інформації у наявних тасках
- Видалення: прибирання виконаних чи непотрібних завдань
- Фільтрація та сортування: упорядкування списку за станом або терміном (опціонально)

## Нефункціональні вимоги

Кросплатформність: підтримка ОС Windows, macOS та Linux.  
Ізоляція модулів: відсутність прямих залежностей між клієнтами, взаємодія суто через файл даних.
Контроль версій: ведення розробки в Git/GitHub через окремі гілки.

## Модулі та технології

- React - веб-інтерфейс
- Electron / NW.js - десктопна обгортка
- C++ / Qt - нативний десктопний клієнт
- Python / Flet - аналітична панель

## Формат обміну даними

- frontend/ - React-фронтенд
- desktop-container/ - Electron/NW.js-контейнер
- cpp-core/ - нативний C++/Qt-клієнт
- python-analytics/ - аналітичний модуль на Python
- data/ - спільний файл обміну даними tasks.json
